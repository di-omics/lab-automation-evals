## The plate-reader grader (la01)

The same plans, graded only from what a plate reader would see after the run with a fluorescent dye in place of the compounds: clean control wells, equal top wells, and a 3-fold drop between neighbouring columns above the detection limit. See [PLATE_READER.md](PLATE_READER.md).
